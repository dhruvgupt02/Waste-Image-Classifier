♻ EcoSort AI
Intelligent Waste Classification using Azure Custom Vision
🚀 Smart Recycling Through Artificial Intelligence

A futuristic AI-powered web application that classifies waste materials into recyclable and non-recyclable categories using Microsoft Azure Custom Vision.

🌱 Introduction

Waste management is one of the biggest environmental challenges in modern society. Improper segregation of recyclable and non-recyclable waste leads to:

Environmental pollution
Increased landfill waste
Poor recycling efficiency
Higher waste management costs

EcoSort Vision AI solves this problem by using Artificial Intelligence to automatically identify whether an uploaded waste item is recyclable or not.

The application uses:

🧠 AI-based image classification
☁ Microsoft Azure Custom Vision
🎨 Modern futuristic UI design
⚡ Real-time prediction system

This project demonstrates the practical implementation of:

Cloud Computing
Computer Vision
Frontend Development
REST APIs
AI Integration
