<h1>♻ EcoSort AI</h1>

<h2>Intelligent Waste Classification using Azure Custom Vision</h2>
<h3>🚀 Smart Recycling Through Artificial Intelligence</h3>

<p>A futuristic AI-powered web application that classifies waste materials into recyclable and non-recyclable categories using Microsoft Azure Custom Vision.</p>

<h2>🌱 Introduction</h2>

<p>Waste management is one of the biggest environmental challenges in modern society. Improper segregation of recyclable and non-recyclable waste leads to:</p>

<ul>
  <li>Environmental pollution</li>
  <li>Increased landfill waste</li>
  <li>Poor recycling efficiency</li>
  <li>Higher waste management costs</li>
</ul>

<p>EcoSort Vision AI solves this problem by using Artificial Intelligence to automatically identify whether an uploaded waste item is recyclable or not.</p>

<p><strong>The application uses:</strong></p>
<ul>
  <li>🧠 AI-based image classification</li>
  <li>☁️ Microsoft Azure Custom Vision</li>
  <li>🎨 Modern futuristic UI design</li>
  <li>⚡ Real-time prediction system</li>
</ul>

<p><strong>This project demonstrates the practical implementation of:</strong></p>
<ul>
  <li>Cloud Computing</li>
  <li>Computer Vision</li>
  <li>Frontend Development</li>
  <li>REST APIs</li>
  <li>AI Integration</li>
</ul>
